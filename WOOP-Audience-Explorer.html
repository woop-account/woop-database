How these numbers are estimated
  • On file today is the count of consented moms and their data points in WOOP's database right now. It reflects the client briefs WOOP has run, so some age groups are deeper than others. A mom with children in different age groups is counted in each group, and a mom can appear in more than one macro audience (for example Kids and Pets).
  • We can add is WOOP's monthly scale for the macro audience, multiplied by the share of that scale that fits the nano audience (for micro audiences, the share of the macro scale). It is our capability if a matching brief came in, not a forecast of what will be acquired.
  • Relevance window is how long a mom stays in an audience. A newborn audience empties as babies grow, so we assume moms on file are spread evenly across the window and age out steadily.
  • Several audiences at once show a range. Moms can sit in more than one audience, so the true combined count falls between the largest single audience and the sum of all of them. WOOP can supply the exact de-duplicated count.
